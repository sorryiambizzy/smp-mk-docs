# Быстрое добавление комментария. iOS

[Для Android](../../how-to-use-2/comments-2/comment-add-2)

### Описание

Быстрое добавление комментария доступно в онлайн и офлайн-режиме.

Возможность добавления комментариев зависит от прав доступа текущего пользователя.

### Место в интерфейсе

Экран "Комментарии ()".

### Выполнение действия

1. Откройте экран "Комментарии ()".
2. Нажмите на поле ввода комментария на нижней панели экрана и введите текст комментария с помощью стандартных виджетов ввода текста iOS.

    
3. Дополнительные возможности:
    - Отметить как приватный — чтобы отметить комментарий как приватный, включите переключатель "Приватный".

        Переключатель отображается, если у пользователя есть права на добавление приватных комментариев.
    - Прикрепить файл из библиотеки или фото — нажмите иконку ![](../../how-to-use-2/comments-2/i_file.png){height=12} и выберите соответствующую функцию мобильного устройства.

        Добавленный файл отображается над полем ввода комментария. Рядом с иконкой ![](../../how-to-use-2/comments-2/i_file.png){height=12} отображается количество прикрепленных файлов.

        Иконки в нижней панели экрана недоступны для нажатия до полной загрузки всех прикрепленных файлов.
    - Добавить форматирование и/или заполнить дополнительные атрибуты — нажмите иконку ![](../../how-to-use-2/comments-2/01_1.png) для перехода на отдельный экран, см. [Расширенное добавление комментария. iOS](./comment-add-ext).

        Иконка недоступна для нажатия, пока грузится хотя бы одно изображение, прикрепленное к комментарию.
4. Нажмите иконку "Отправить комментарий". Добавление комментария будет завершено.

### Результат действия

Новый комментарий отобразится на экране "Комментарии ()". Приватные комментарии отмечены надписью "Приватный".

Все изображения, вставленные в комментарий, отображаются в конце сообщения отдельным блоком. Максимум выводится три превью. Если картинок больше трех, то третья картинка затемняется, а на фоне пишется сколько еще картинок не выведено с учетом текущей картинки.

Особенности офлайн-режима:

- Для добавления комментария в офлайн-режиме экран карточки объекта должен быть сохранен в кеше приложения.
- После добавления комментарий помещается в очередь синхронизации. На экране отображается сообщение: "Комментарий добавлен в очередь синхронизации и будет отправлен при появлении доступа к серверу".
- Время добавления комментария будет соответствовать дате и времени синхронизации с сервером.

Подробное описание офлайн-режима приведено в разделе [Офлайн-режим. iOS](../offline).
