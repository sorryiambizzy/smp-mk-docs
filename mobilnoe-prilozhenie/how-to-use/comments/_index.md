[Для Android](../../how-to-use-2/comments-2)

Для работы с комментариями в мобильном приложении предназначены экран "Комментарии" и некоторые экраны редактирования объектов, на которых размещено поле добавления комментария.

- [Просмотр комментариев. iOS](./comment-view)

    Комментарии к объекту отображаются на отдельном экране "Комментарии ()". Экран комментария предназначен для отображения подробной информации о комментарии.
- [Быстрое добавление комментария. iOS](./comment-add)

    В мобильном приложении можно добавить комментарий с помощью клавиатуры вручную.
- [Расширенное добавление комментария. iOS](./comment-add-ext)

    В мобильном приложении можно добавить комментарий с форматированием текста.
- [Меню действий с комментарием. iOS](./comment-actions)

    С помощью меню действий можно перейти на карточку комментария, отредактировать или удалить комментарий.
