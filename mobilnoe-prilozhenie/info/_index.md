# Мобильное приложение (МК)

#### Описание

Мобильное приложение позволяет:

- Всегда быть в курсе рабочих дел и оперативно получать информацию в любое время, где бы вы не находились.
- Держать в поле зрения все важные задачи в вашей ответственности.
- Получать и назначать задачи, даже пока вы в пути.

Мобильное приложение ориентировано на выездных специалистов инженерной службы, получателей услуг, руководителей разного уровня, а также сотрудников любых сервисных служб компании, которые заинтересованы в оперативном управлении процессами, особенно в ситуациях, когда они находятся вне рабочего места.

#### Примеры бизнес-кейсов

Примеры бизнес-кейсов, которые решаются с помощью мобильного приложения:

- **Регистрация нового обращения**:

    Пользователь регистрирует новый запрос и заполняет описание возникшего сбоя или ошибки.
- **Обработка обращения выездным инженером (прокладка маршрута)**:

    Инженер получает уведомление о поступлении запроса в свою ответственность.

    Переходит на карточку запроса и изучает информацию по запросу.

    Прокладывает маршрут "мое местоположение — адрес контрагента запроса" и уточняет время своего приезда в карточке запроса.

    Инженер может связаться с контрагентом по телефону, указанному в контактных данных.
- **Обработка обращения выездным инженером (переклассификация запроса)**:

    Инженер открывает список запросов в своей ответственности.

    Переходит на карточку запроса и изменяет неверно определенный тип запроса.
- **Обработка обращения выездным инженером (переписка по запросу)**:

    Инженер открывает список запросов в своей ответственности.

    Переходит на карточку запроса и изучает информацию по запросу. Просматривает и ведет переписку по запросу.
- **Оперативный доступ к базе знаний**, в которой публикуются инструкции по выполнению стандартных действий в системе, полезная информация для решения типичных инцидентов и обходные решения известных проблем.

    Пользователь открывает список разделов, выбирает разделы и просматривает интересующие его статьи базы знаний.
- **Согласование с руководителем**:

    Руководитель открывает список своих согласований.

    Переходит на карточку согласования, изучает информацию по предмету согласования и срокам проведения согласования, затем выражает свое мнение по заявленному вопросу согласования: согласовывает или отклоняет.
- **Подтверждение работ по обращению**:

    Пользователь открывает список запросов, ожидающих подтверждение выполнения.

    Переходит на карточку запроса, изучает информацию по запросу и просматривает переписку по запросу.

    Закрывает запрос и выставляет оценку работы специалистов.
