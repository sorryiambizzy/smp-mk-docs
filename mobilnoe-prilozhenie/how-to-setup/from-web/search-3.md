# Поиск объектов

Особенности поиска в мобильном приложении:

- Поиск выполняется только по объектам, для которых настроены карточки в мобильном приложении, см. [Карточка объекта](../cards).
- Архивные объекты в поиске не участвуют и не учитываются при отображении результатов поиска.

На поиск в мобильном приложении распространяются настройки поиска в веб-интерфейсе:

- Общие настройки поиска, например, максимальное количество объектов в результатах быстрого поиска. Подробнее в документации SMP в разделе [Общие настройки поиска](https://www.naumen.ru/docs/sd/nsmp/Content/search/search_setting_general.htm).
- Быстрый поиск настраивается для каждого класса/типа объектов на вкладке "Поиск". Подробнее в документации SMP в разделе [Настройка поиска в классе и типе объектов](https://www.naumen.ru/docs/sd/nsmp/Content/search/search_setting.htm).
- Контроль прав при поиске. Использование механизма контроля прав пользователя при отображении результатов поиска объектов позволяет отображать список результатов поиска с учетом условий фильтрации, заданных для роли текущего пользователя. Подробнее в документации SMP в разделе [Контроль прав при поиске](https://www.naumen.ru/docs/sd/nsmp/Content/search/Control_rights_searching_objects.htm).
- Набор атрибутов объекта, которые будут отображаться на экране результатов поиска, настраивается для каждого класса/типа объектов на вкладке "Группы атрибутов":
    - группа атрибутов "Атрибуты результатов поиска в мобильном приложении для лицензированных пользователей" используется для отображения результатов поиска для лицензированных пользователей.
    - группа атрибутов "Атрибуты результатов поиска в мобильном приложении для нелицензированных пользователей" используется для отображения результатов поиска для нелицензированных пользователей.

    Настройка группы атрибутов выполняется по общим правилам. Подробнее в документации SMP в разделе [Группы атрибутов](https://www.naumen.ru/docs/sd/nsmp/Content/Attr/attribute_group_setting.htm).
