# Смена ответственного

### Описание процесса

Пользователь нажимает "Изменить ответственного" в меню действий с объектом или на карточке объекта → открывается экран "Смена ответственного" → пользователь заполняет поля атрибутов → пользователь нажимает кнопку подтверждения действия → выполняется изменение ответственного.

Выполнение изменения ответственного в мобильном приложении:

- [Сменить ответственного. Android](../../how-to-use-2/actions-2/change-assignee-2)
- [Сменить ответственного. iOS](../../how-to-use/actions/change-assignee)

### Настройка процесса

Для смены ответственного в мобильном приложении необходимы следующие настройки в веб-интерфейсе:

- Пункт "Изменить ответственного" отображается при использовании системной настройки меню, см. [Включение системного меню действий с объектом](../cards/card-actions#sistem). Пункт меню отображается только для объектов класса с возможность назначения ответственного.

    Пункт "Изменить ответственного" может быть скрыт, см. [Удаление элемента меню](../cards/card-actions#dell).
- Элемент управления "Изменить ответственного" в виде кнопки, иконки или ссылки может быть размещен на карточке объекта, см. [Настройка действий в контенте](../cards/card-view/card-obj-parameters#act).
- Экран "Смена ответственного".

    На содержание экрана распространяется настройка формы изменения ответственного в веб-интерфейсе. Подробнее в документации SMP в разделе [Форма смены ответственного](https://www.naumen.ru/docs/sd/nsmp/Content/TypesClasses/form_responsible_setting.htm).
- Кнопки **Себе** и **Своей команде** используются для быстрого заполнения атрибута "Ответственный" (responsible).

    Кнопки отображаются на экранах смены ответственного, редактирования, изменения статуса, изменения типа и изменения привязки при наличии поля атрибута "Ответственный" (responsible) и соблюдении условий отображения.

    Кнопка **Себе** отображается, если:
    - сотрудник имеет право на прием объекта в свою ответственность;
    - в поле атрибута "Ответственный" (responsible) указана команда текущего пользователя или сотрудник из его команды;
    - атрибут текущего статуса "Класс ответственного в статусе" не равен "команды" (при наличии у объекта жизненного цикла);
    - скрипт фильтрации значений при редактировании, настроенный для атрибута "Ответственный" (responsible), не ограничивает прием объекта в свою ответственность.

    Кнопка **Своей команде** отображается, если:
    - сотрудник имеет право на назначение своей команды ответственной за объект;
    - в поле атрибута "Ответственный" указан текущий пользователь или сотрудник из его команды;
    - атрибут текущего статуса "Класс ответственного в статусе" не равен "сотрудники" (при наличии у объекта жизненного цикла);
    - скрипт фильтрации значений при редактировании, настроенный для атрибута "Ответственный" (responsible), не ограничивает назначение своей команды ответственной за объект.
- Права.

    Возможность изменения ответственного зависит от прав доступа текущего пользователя. Настройка прав доступа выполняется в веб-интерфейсе для класса объектов, у которого установлен признак "Назначение ответственного" (группа прав "Изменение ответственного").
