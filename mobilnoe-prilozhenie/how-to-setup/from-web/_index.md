# Наследуемые настройки

Наследуемые настройки — это настройки SMP, выполняемые в интерфейсе администратора (кроме раздела "Настройки системы" → "Мобильное приложение"). 
Данные настройки распространяются и на мобильное приложение, и на веб-приложение SMP.

- [Поиск объектов](./search-3)
- [Уведомления](./notifications-3)
- [Настройка комментариев](./comments-3)
- [Смена статуса](./change-state-3)
- [Смена ответственного](./change-assignee-3)
- [Смена типа](./change-type-3)
- [Смена привязки](./change-association-3)
- [Скриптовые методы](./scripts)

На мобильное приложение распространяются настройки параметров отображения атрибутов, выполненные в веб-интерфейсе, с некоторыми особенностями:

- настройка автоматического выбора единственного значения атрибута на форме распространяется на все формы в мобильном приложении;
- настройка параметра атрибута "Скрывать поле с формы, если доступных значений нет" распространяется на все формы в мобильном приложении;
- значение параметра "Скрывать при отображении, если не заполнен" не влияет на отображение атрибута на карточке в мобильном приложении. Если значение атрибута не указано, то данный атрибут всегда скрывается на карточке объекта.
