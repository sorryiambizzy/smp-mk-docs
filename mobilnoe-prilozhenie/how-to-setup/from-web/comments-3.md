# Комментарии

Для работы с комментариями в мобильном приложении необходимы следующие настройки в веб-интерфейсе:

- Карточка комментария.

    На экране карточки комментария в блоке "Подробнее" отображаются атрибуты из группы атрибутов "Подробнее" служебного класса "Комментарий". Порядок атрибутов на форме такой же, как в группе атрибутов. Подробнее в документации SMP в разделе [Служебный класс "Комментарий" (comment)](https://www.naumen.ru/docs/sd/nsmp/Content/prava/comm_class.htm).
- Формы добавления и редактирования комментария.

    На форме добавления комментария расположены атрибуты из группы атрибутов "Форма добавления" служебного класса "Комментарий". Отображаются только те атрибуты из группы, на редактирование которых у пользователя есть право. Порядок атрибутов на форме такой же, как в группе атрибутов.

    На форме добавления комментария расположены атрибуты из группы атрибутов "Форма редактирования" служебного класса "Комментарий". Отображаются только те атрибуты из группы, на редактирование которых у пользователя есть право. Порядок атрибутов на форме такой же, как в группе атрибутов. Подробнее в документации SMP в разделе [Группы атрибутов](https://www.naumen.ru/docs/sd/nsmp/Content/Attr/attribute_group_setting.htm).
- Права.

    Настройка прав для работы с комментариями выполняется для класса объектов, для которого отображаются и добавляются комментарии. Подробнее в документации SMP в разделе [Права на работу с комментариями](https://www.naumen.ru/docs/sd/nsmp/Content/prava/rules_comm_rules.htm).
- Автор комментария.
    - Иконка автора комментария отображается на экране "Комментарии" рядом с полем "Автор комментария".

        Иконка автора комментария настраивается в атрибуте "Фотография" (image) объектов класса "Сотрудник" (employee). Если у сотрудника не установлен аватар, то отображается цветной круг с инициалами пользователя
    - Если у текущего пользователя нет права на просмотр автора комментария, то на экране "Комментарии" в поле "Автор комментария" отображается псевдоним автора.

        Псевдоним настраивается в атрибуте "Псевдоним" (commentAuthorAlias) объектов класса "Сотрудник" (employee).

        Если у автора комментария не заполнен атрибут "Псевдоним" (commentAuthorAlias), то используется значение "Сотрудник" (employee).
    - Если автор комментария суперпользователь, то для подписи используется значение параметра "Название системы"  на странице "Администрирование" → блок "Прочие настройки".
- Приватность комментария.
    - В полоске настройки приватности отображается название атрибута с кодом private служебного класса "Комментарий".

        По умолчанию используется атрибут "Приватный" (значение по умолчанию "Нет").
    - Состояние кнопки присвоения признака приватности в строке настройки приватности зависит от значения по умолчанию атрибута "Приватный" (private):
        - Если значение атрибута по умолчанию "Да", то кнопка подсвечивается синим и в кнопке отображается галочка.
        - Если значение атрибута по умолчанию "Нет", то кнопка подсвечивается серым.
