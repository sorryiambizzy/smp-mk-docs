# Смена типа

### Описание процесса

Пользователь нажимает "Изменить тип" в меню действий с объектом или на карточке объекта → открывается экран "Изменение типа" → пользователь выбирает новый тип и заполняет поля атрибутов (если при смене типа требуется заполнение атрибутов объекта) → пользователь нажимает кнопку подтверждения действия → выполняется изменение типа объекта.

Выполнение смены типа в мобильном приложении:

- [Сменить тип. Android](../../how-to-use-2/actions-2/change-type-2)
- [Сменить тип. iOS](../../how-to-use/actions/change-type)

### Настройка процесса

Для смены типа объекта в мобильном приложении необходимы следующие настройки в веб-интерфейсе:

- Пункт "Изменить тип" в меню действий с объектом отображается при использовании системной настройки меню, см. [Включение системного меню действий с объектом](../cards/card-actions).

    Пункт "Изменить тип" может быть скрыт, см. [Удаление элемента меню](../cards/card-actions).
- Элемент управления "Изменить тип" в виде кнопки, иконки или ссылки может быть размещен на карточке объекта, см. [Настройка действий в контенте](../cards/card-view/card-obj-parameters).
- Экран "Изменение типа".

    На содержание экрана "Изменение типа" распространяется настройка формы смены типа в веб-интерфейсе. Подробнее в документации SMP в разделе [Форма смены типа объекта](https://www.naumen.ru/docs/sd/nsmp/Content/TypesClasses/form_tip_setting.htm).

    При смене типа будет использоваться системная форма смены типа или пользовательская форма (если она настроена) по аналогии с веб-интерфейсом.
- Права.

    Возможность смены типа объекта зависит от прав доступа текущего пользователя.
