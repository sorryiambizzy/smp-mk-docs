# Смена статуса

### Описание процесса

Пользователь нажимает кнопку смены статуса в меню действий с объектом или название статуса (выделенное цветом с шевроном) на карточке объекта → открывается форма выбора целевого статуса, на которую выведены все доступные переходы из текущего статуса → пользователь выбирает целевой статус → открывается экран "Изменение статуса" (если при смене статуса требуется заполнение атрибутов объекта) или выполняется переход в выбранный статус.

- [Сменить статус. Android](../../how-to-use-2/actions-2/change-state-2)
- [Сменить статус. iOS](../../how-to-use/actions/change-state)

### Настройка процесса

Для смены статуса объекта в мобильном приложении необходимы следующие настройки в веб-интерфейсе:

- Пункт "Изменить статус" в меню действий с объектом отображается при использовании системной настройки меню, см. [Включение системного меню действий с объектом](../cards/card-actions#sistem).

    Пункт "Изменить статус" может быть скрыт, см. [Удаление элемента меню](../cards/card-actions#dell).
- Элемент управления "Изменить статус" в виде кнопки, иконки или ссылки может быть размещен на карточке объекта, см. [Настройка действий в контенте](../cards/card-view/card-obj-parameters#act).
- Быстрая смена статуса.

    Возможность вызвать форму выбора целевого статуса при нажатии на название статуса (выделенное цветом с шевроном) на карточке объекта включается в разделе "Мобильное приложение" → "Карточки объектов" (параметр "Быстрая смена статуса доступна"), см. [Добавление карточки](../cards/card-create).

    Для выбора будут доступны переходы между статусам, для которых явно указаны названия.
- Форма выбора целевого статуса

    На форме выбора целевого статуса отображается название перехода (если оно определено) или название целевого статуса.

    Набор целевых статусов определяется при настройке карточки объекта в мобильном приложении в разделе "Мобильное приложение" → "Карточки объектов" (параметры "Использовать настройку переходов между статусами из веб-клиента" и "Доступные переходы между статусами"), см. [Добавление карточки](../cards/card-create).

    Названия переходов и статусов настраиваются в веб-интерфейсе. Подробнее в документации SMP в разделах [Добавление статуса объекта](https://www.naumen.ru/docs/sd/nsmp/Content/Life_cycle/status_add_toc.htm) и [Добавление перехода между статусами](https://www.naumen.ru/docs/sd/nsmp/Content/LC_transfer/transfer_add.htm).
- Экран "Изменение статуса".

    На содержание экрана "Изменение статуса" распространяется настройка формы смены статуса в веб-интерфейсе, включая порядок отображения атрибутов. Подробнее в документации SMP в разделе [Форма смены статуса жизненного цикла](https://www.naumen.ru/docs/sd/nsmp/Content/Life_cycle/form_status.htm).
- Права.

    Возможность смены статуса объекта зависит от прав доступа текущего пользователя. Настройка прав доступа выполняется в веб-интерфейсе для класса объектов, у которого установлен признак "Жизненный цикл".
