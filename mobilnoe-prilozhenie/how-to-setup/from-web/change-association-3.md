# Смена привязки

### Описание процесса

Пользователь нажимает "Изменить привязку" в меню действий с объектом или на карточке объекта → открывается экран "Изменение привязки" → пользователь заполняет поля атрибутов → пользователь нажимает кнопку подтверждения действия → выполняется изменение привязки запроса.

Выполнение изменения привязки в мобильном приложении:

- [Сменить привязку. Android](../../how-to-use-2/actions-2/change-association-2)
- [Сменить привязку. iOS](../../how-to-use/actions/change-association)

### Настройка процесса

Для смены типа объекта в мобильном приложении необходимы следующие настройки в веб-интерфейсе:

- Пункт "Изменить привязку" в меню действий с объектом отображается при использовании системной настройки меню, см. [Включение системного меню действий с объектом](../cards/card-actions#sistem).

    Пункт "Изменить привязку" может быть скрыт, см. [Удаление элемента меню](../cards/card-actions#dell).
- Элемент управления "Изменить привязку" в виде кнопки, иконки или ссылки может быть размещен на карточке объекта, см. [Настройка действий в контенте](../cards/card-view/card-obj-parameters#act).
- Экран "Изменение привязки".

    На содержание экрана "Изменение привязки" распространяется настройка формы изменения привязки в веб-интерфейсе. Подробнее в документации SMP в разделе [Изменение привязки запроса](https://www.naumen.ru/docs/sd/nsmp/Content/request/call_linking.htm).
- Права.

    Возможность изменения привязки запроса зависит от прав доступа текущего пользователя, настройка прав доступа выполняется в веб-интерфейсе для класса "Запрос" (serviceCall).
