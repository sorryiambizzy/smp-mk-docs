# Формы редактирования объектов

Форма редактирования объектов отображается на отдельном экране мобильного приложения.

Для работы с формой редактирования в мобильном приложении необходимо выполнить следующие настройки:

- [Добавление формы редактирования объектов](./edit-form-create)

    В мобильном приложении можно создать новую форму редактирования. Для класса/типа объектов могут быть созданы одна или несколько форм редактирования.

    При настройке действия "Редактировать" в меню действий с объектом  или в контенте может быть выбрана конкретная форма редактирования, которая будет открываться при выполнении действия в мобильном приложении. Если при настройке действия форма не выбрана, то в мобильном приложении открывается первая по списку форма редактирования для объекта определенного класса/типа.
- [Параметры формы редактирования](./edit-form-parameters)

    На странице настройки формы редактирования можно внести изменения в параметры формы редактирования, указанные при добавлении.
- [Атрибуты на форме редактирования](./edit-form-attributes)

    На странице настройки формы редактирования можно сформировать набор атрибутов объекта для отображения на форме редактирования.
