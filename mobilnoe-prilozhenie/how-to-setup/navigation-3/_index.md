# Навигация

Навигация по системе в мобильном приложении настраивается на вкладке "Навигация".

Для настройки меню в мобильном приложении включают в себя:

- [Добавление элемента меню](./navigation-items-create)

    В меню мобильного приложения можно добавить разделы, кнопки добавления объектов, ссылки на списки и карточки объектов, кнопку сканирования штрих-кодови ссылки на встроенные приложения.
- [Атрибуты элемента меню](./navigation-items-edit)

    Настройка элементов меню включает в себя следующие действия: управление порядком расположения элементов меню, редактирование элемента меню и удаление элемента меню.
