# Атрибуты элемента меню

- [Редактирование параметров списка объектов](#edit)
- [Удаление карточки объектов](#dell)

### Редактирование параметров элемента меню

#### Место настройки в интерфейсе

Меню навигации "Настройка системы" → настройка "Мобильное приложение" → вкладка "Навигация" → страница настройки элемента меню в мобильном приложении → блок "Атрибуты элемента".

Поля блока "Атрибуты элемента":

- Название.
- Вложен в раздел.
- Вид элемента.
- Содержимое.
- Метки.

Также параметры элемента меню можно изменить на вкладке "Навигация", нажав иконку редактирования ![](../cards/edit.PNG) в строке элемента.

#### Выполнение настройки

В блоке "Атрибуты элемента" нажмите кнопку **Редактировать**. На форме "Редактирование элемента меню" измените параметры и нажмите **Сохранить**.

<note type="info">

Параметр "Вид элемента" не редактируется.

</note>

Форма редактирования закроется, внесенные изменения будут применены, параметры элемента меню обновятся.

### Удаление элемента меню

#### Место настройки в интерфейсе

Меню навигации "Настройка системы" → настройка "Мобильное приложение" → вкладка "Навигация" → страница настройки элемента меню в мобильном приложении → блок "Атрибуты элемента".

Также элемент меню можно удалить на вкладке "Навигация", нажав иконку удаления ![](../add-form/del_01.PNG) в строке элемента.

#### Выполнение настройки

В блоке "Атрибуты элемента" нажмите кнопку **Удалить**.

Подтвердите действие, нажав кнопку **Да**.
Вместе с элементом меню удаляются все вложенные в него элементы.
