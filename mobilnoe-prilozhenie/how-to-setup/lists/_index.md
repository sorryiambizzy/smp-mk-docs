title: Списки объектов
---

Список объектов, добавленный на страницу "Мобильное приложение", может использоваться в мобильном приложении. Каждый список объектов отображается на отдельном экране и содержит объекты одного класса. При нажатии на элемент списка выполняется переход на карточку объекта, если она настроена для мобильного приложения.

Для работы со списком объектов в мобильном приложении необходимо выполнить следующие настройки:

- [Добавление списка](./list-create)

    В мобильном приложении можно отображать два варианта списка объектов: список объектов определенного класса/типа или список объектов определенного класса/типа, связанный через атрибут (цепочку атрибутов) с текущим пользователем.
- [Параметры списка](./list-parameters)

    На странице настройки списка объектов можно внести изменения в параметры списка, указанные при добавлении, копировать настройки списка или удалить список.
- [Фильтрация списка](./list-filter)

    На странице настройки списка объектов можно настроить фильтрацию списка. Фильтрация позволяет отображать в списке не все объекты выбранного класса/типов, а только объекты с заданными характеристиками. Фильтрация настраивается для каждого списка отдельно. По умолчанию фильтрация списка объектов не настроена.
- [Сортировка списка](./list-sort)

    На странице настройки списка объектов можно настроить сортировку списка. Сортировка позволяет отображать в списке объекты в заданном порядке. Сортировка настраивается для каждого списка отдельно. По умолчанию сортировка списка объектов не настроена.
- [Атрибуты в списке](./list-attributes)

    На странице настройки списка объектов можно сформировать набор атрибутов объекта для отображения в списке. В список объектов можно вывести атрибуты, созданные в классе и типах объектов, выбранных при добавлении списка. По умолчанию список атрибутов для списка пуст.
