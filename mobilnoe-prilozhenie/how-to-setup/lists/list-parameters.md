### Редактирование параметров списка объектов

#### Место настройки в интерфейсе

Меню навигации "Настройка системы" → настройка "Мобильное приложение" → вкладка "Списки объектов" → страница настройки списка объектов в мобильном приложении → блок "Параметры списка".

![Страница настройки списка объектов для мобильного приложения.](../cards/IT_03_411.png)

Поля блока "Параметры списка":

- Название.
- Код.
- Класс.
- Типы.
- Связь с текущим пользователем.
- Доступен профилям.
- Места использования — информация о том, где используется список объектов в мобильном приложении.
- Метки.
- Разрешить действия с объектами из списка.

#### Выполнение настройки

В блоке "Параметры списка" нажмите кнопку **Редактировать**. На форме "Редактирование списка" измените параметры списка объектов и нажмите **Сохранить**.

<note type="info">

Параметр "Код" не редактируется.
При изменении параметра "Класс" сбрасываются настройки атрибутов, фильтрации и сортировки списка.

</note>

### Копирование списка объектов

#### Описание настройки

Операция копирования позволяет быстро воспроизводить однотипные настройки списка объектов — создать новый список объектов и скопировать в него настройки уже существующего списка объектов.

#### Место настройки в интерфейсе

Меню навигации "Настройка системы" → настройка "Мобильное приложение" → вкладка "Списки объектов" → страница настройки списка объектов в мобильном приложении → блок "Параметры списка".

#### Выполнение настройки

В блоке "Параметры списка" нажмите кнопку **Копировать**. На форме "Копирование списка" заполните поля "Название", "Код" и нажмите **Сохранить**.

Форма копирования закроется, на экране отобразится страница настройки нового списка объектов. В скопированные настройки списка объектов можно вносить изменения, см. [Редактирование параметров списка объектов](#edit).

#### Связанные настройки

Для отображения списка в меню мобильного приложения необходимо настроить соответствующий элемент на вкладке "Навигация". Описание добавления элементов меню приводится в разделе [Добавление элементов меню.](../navigation-3/navigation-items-create)

### Удаление списка объектов

#### Место настройки в интерфейсе

Меню навигации "Настройка системы" → настройка "Мобильное приложение" → вкладка "Списки объектов" → страница настройки списка объектов в мобильном приложении → блок "Параметры списка".

Также список можно удалить на вкладке "Списки объектов", нажав иконку удаления ![](../add-form/del_01.PNG) в строке списка.

#### Выполнение настройки

В блоке "Параметры списка" нажмите кнопку **Удалить**.

Список объектов будет недоступен для просмотра в мобильном приложении и перестанет отображаться на вкладке "Списки объектов".
