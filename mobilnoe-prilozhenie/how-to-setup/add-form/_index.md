# Формы добавления объектов

Форма добавления отображается на отдельном экране мобильного приложения. На форму добавления объекта можно перейти из меню мобильного приложения и из меню действий списка объектов.

Для работы с формой добавления в мобильном приложении необходимо выполнить следующие настройки:

- [Создание формы добавления объектов](./add-form-create)

    В мобильном приложении можно создать новую форму добавления.
- [Параметры формы добавления](./add-form-parameters)

    На странице настройки формы добавления можно внести изменения в параметры формы добавления, указанные при добавлении.
- [Атрибуты на форме добавления](./add-form-attributes)

    На странице настройки формы добавления можно сформировать набор атрибутов объекта для отображения на форме добавления.
- [Создание объекта голосом](./add-form-voice)

    На странице настройки формы добавления можно настроить возможность голосового создания объектов.
