### Описание настройки

Возможность голосового создания объектов определяется для каждого класса объектов отдельно при настройке формы добавления объектов данного класса.

<note type="info">

Для голосового создания объектов необходимо включить доступ к микрофону и голосовому вводу на мобильном устройстве.

</note>

#### Наследование

Если при создании формы добавления указана родительская форма (заполнен параметр "Родитель"), то настройка атрибутов наследуется из родительской формы. Чтобы изменить существующие настройки необходимо разорвать наследование (кнопка **Разорвать наследование**). Наследование восстанавливается при нажатии кнопки **Восстановить наследование**.

### Место настройки в интерфейсе

Меню навигации "Настройка системы" → настройка "Мобильное приложение" → вкладка "Формы добавления объектов" → страница настройки формы добавления в мобильном приложении → блок "Создание объекта голосом".

![Страница "Форма добавления объектов"](./IT_43_416.png)

### Выполнение настройки

В блоке "Создание объекта голосом" нажмите кнопку **Редактировать**, заполните параметры и нажмите **Сохранить**.

Параметры создания объектов голосом:

- **Разрешить создавать объекты голосом** — включает/отключает возможность создания объекта голосом:
    - Флажок включен — в мобильном приложении возможно голосовое создание объектов. В меню мобильного приложения справа от названия кнопки добавления будет отображаться иконка **микрофон** и на форме добавления объекта будет отображаться кнопка **Создать голосом**, при нажатии на которые будет открываться форма голосового создания.
        - [Добавить. iOS](../../how-to-use/actions/add)
        - [Добавить. Android](../../how-to-use-2/actions-2/add-2)
    - флажок отключен (по умолчанию) — создание объекта голосом выключено, иконка **микрофон** и кнопка **Создать голосом** не отображаются.
- **Сохранить расшифровку голоса в атрибут** (для iOS) — выбирается атрибут типа "Текст в формате RTF" и "Текст", в который будет сохраняться текст, полученный при расшифровке записи голоса.

    Для выбора доступны атрибуты класса объектов, который выбран в параметре "Класс" формы добавления. Если для формы добавления указан параметр "Типы", то для выбора доступны только атрибуты указанного типа объектов.

    Необходимо добавить специальный атрибут для хранения текстовой расшифровки записи голоса.

    По умолчанию выбрано [не указано] и текст расшифровки записи голоса не сохраняется.
- **Обрабатывать параметры при создании** — определяет скриптовую логику заполнения атрибутов создаваемого объекта. По умолчанию "нет" — атрибуты создаваемого объекта заполняются значениями по умолчанию.

### Результат настройки

Если включена возможность создания объектов голосом, то в меню мобильного приложения справа от названия кнопки добавления отображается иконка **микрофон** и на форме добавления объекта отображается кнопка **Создать голосом**, при нажатии на которые открывается форма голосового создания.

Если возможность голосового создания объектов отключена, то в меню мобильного приложения иконка **микрофон** и кнопка **Создать голосом** не отображаются.
