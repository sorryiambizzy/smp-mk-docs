## Локализация названий классов и атрибутов {#localization}

#### Описание настройки

Название классов/типов объектов и атрибутов формируется или изменяется в интерфейсе администратора при выполнении настройки системы.

#### Условие настройки

Переключите язык интерфейса, для этого перейдите по ссылке с именем пользователя в правом верхнем углу 
				экрана и на странице "Персональные настройки" выберите язык интерфейса: "English" или "Клиентский язык" (немецкий).

#### Место настройки в интерфейсе

Меню навигации "Классы" → класс → вкладка "Атрибуты".

#### Выполнение настройки

Задайте названия объектов настройки системы для выбранного языка:

- названия классов и типов;
- названия атрибутов.

#### Результат настройки

Указанные названия и описания элементов будут применяться при выборе соответствующего языка интерфейса.

Если для английского (клиентского языка) значение не определено, то:

- если данное значение является обязательным, используется значение на русском языке, например, название класса объектов;
- если данное значение не является обязательным, то отображается пустое поле, например, описание класса объектов.

## Локализация названий объектов {#localization_mob}

#### Описание настройки

Название объектов изменяются в интерфейсе администратора при выполнении настройки системы.

#### Условие настройки

Переключите язык интерфейса, для этого перейдите по ссылке с именем пользователя в правом верхнем углу 
				экрана и на странице "Персональные настройки" выберите язык интерфейса: "English" или "Клиентский язык" (немецкий).

#### Место настройки в интерфейсе

Меню навигации "Настройка системы" → "Мобильное приложение".

#### Выполнение настройки

Задайте названия объектов настройки мобильного приложения для выбранного языка:

- название списка объектов, см. [Редактирование параметров списка объектов](./lists/list-parameters#edit);
- название элемента меню действий с объектом, см. [Редактирование элемента меню](./cards/card-actions#edit);
- название контентов на карточке объекта, см. [Настройка интерфейса карточки](./cards/card-view);
- название формы добавления, см. [Редактирование параметров формы добавления](./add-form/add-form-parameters#edit);
- название раздела и элемента меню, см. [Редактирование параметров элемента меню](./navigation-3/navigation-items-edit#edit).

#### Результат настройки

Указанные названия объектов будут применяться при выборе соответствующего языка интерфейса.

## Изменение языка интерфейса {#language_selection}

#### Описание настройки

Язык интерфейса мобильного приложения можно изменить.

#### Место настройки в интерфейсе

Ссылка с именем пользователя в правом верхнем углу 
				экрана → страница "Персональные настройки".

#### Выполнение настройки

На странице "Персональные настройки" выберите значение параметра "Язык интерфейса" и нажмите **Сохранить**.

Возможные значения:

- Русский — язык интерфейса русский, в календаре первый день недели: понедельник.
- English — язык интерфейса английский, в календаре первый день недели: воскресенье.
- Клиентский язык — язык интерфейса клиентский, в календаре первый день недели: понедельник.

#### Результат настройки

В мобильном приложении будут применяться названия объектов настройки, указанные для выбранного языка интерфейса.

#### Последующие настройки

Установите язык интерфейса на мобильном устройстве.

Локальные константы мобильного приложения будут отображаться на выбранном языке.

При выборе языка, отличного от русского и немецкого, информационные сообщения для пользователей отображаются на English.
