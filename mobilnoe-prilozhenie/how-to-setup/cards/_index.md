# Карточки объектов

Карточка объекта в мобильном приложении отображается на отдельном экране.

Для работы с карточкой объекта в мобильном приложении необходимо выполнить следующие настройки:

- [Добавление карточки](./card-create)

    В мобильном приложении можно добавить карточку объекта. В мобильном приложении открывается первая по списку карточка объекта определенного класса/типа, доступная для текущего пользователя.
- [Параметры карточки](./card-parameters)

    На странице настройки карточки объектов можно внести изменения в параметры карточки, указанные при добавлении, копировать настройки карточки или удалить карточку.
- [Настройка действий с объектом](./card-actions)

    На странице настройки карточки объектов можно настроить меню действий с объектом. Меню действий с объектом предназначено для инициации действий с объектом в мобильном приложении. Иконка вызова меню доступна на карточке объекта или в списке объектов.
- [Настройка интерфейса карточки](./card-view)

    На странице настройки карточки объектов можно настроить интерфейс карточки объектов. Интерфейс формируется из контентов, которые содержат разное наполнение в зависимости от своего типа, что позволяет реализовать смысловое деление карточки.
