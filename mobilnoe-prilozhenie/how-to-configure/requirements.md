## Аппаратное обеспечение

Требуемые ресурсы:

- ОЗУ — не менее 512 МБ;
- Дисковое пространство — не менее 200 МБ.

Разрешение экрана мобильного устройства (минимальные требования):

- для iOS устройств — 640х1136 точек,
- для Android устройств — 480x720 точек (HDPI).

## Каналы связи

Для работы в онлайн-режиме требуется стабильное подключение к 3G интернету.

При отсутствии подключения к сети Интернет или серверу, на котором развернута система, мобильное приложение переводится в офлайн-режим с ограниченным доступом к функциям приложения. Актуальный список доступных функций определен для конкретной версии в документации по работе в мобильном приложении для соответствующей операционной системы.

При отсутствии подключения к сети Интернет приостанавливается доставка уведомлений. После возврата в онлайн-режим гарантированная доставка уведомлений, отправленных в офлайн-режиме, отсутствует и определяется сервером рассылки уведомлений Google.

## Сетевые ресурсы

Для работы мобильного приложения из сети Интернет, в том числе отправки push-уведомлений, требуется настроить доступ к сетевым ресурсам, подробнее описано в разделе [Настройка сетевых ресурсов МК](./network).

## Разрешения

Для мобильного приложения должны быть предоставлены следующие разрешения:

- Камера — съемка фотографий и видеозаписей.

    Разрешение запрашивается при добавлении фото или видео на экранах "Файлы", "Комментарии", при редактировании атрибута типа "Файл", при использовании сканера штрих-кодов.
- Местоположение — доступ к текущему местоположению устройства.

    Разрешение запрашивается во время выполнения следующих действий:
    - пользовательское действие, для которого включен признак "Передавать геопозицию устройства";
    - системное действие, для которого включен признак "Передавать геопозицию устройства";
    - включение настройки приложения "Доступ к местоположению".
        - [Настройка доступа к местоположению устройства](../how-to-use/navigation/settings/app-settings) (iOS)
        - [Настройка доступа к местоположению устройства](../how-to-use-2/navigation-2/settings-2/app-settings-2) (Android)

    Разрешение запрашивается для фоновых сервисов при запуске приложения и при авторизации, если включен режим отслеживания перемещений хотя бы для одного аккаунта.

    Для работы геосервисов необходимо предоставлять разрешение на передачу точной геопозиции.
- Уведомления — отправка пользователю пуш-уведомлений.

    На iOS разрешение запрашивается сразу после установки приложения.
- Микрофон — запись аудио с микрофона устройства при использовании формы голосового создания объекта.

    Разрешение запрашивается при открытии формы голосового создания объекта.
- Распознавание речи (для iOS) — перевод в текст голоса, полученного с микрофона устройства на форме голосового создания объекта.

    Разрешение запрашивается при открытии формы голосового создания объекта.
- Разрешения на вход с биометрией (сканер отпечатка пальца и Face ID).
