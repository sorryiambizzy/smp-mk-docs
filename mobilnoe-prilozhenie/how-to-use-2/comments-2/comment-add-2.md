# Быстрое добавление комментария. Android

[Для iOS](../../how-to-use/comments/comment-add)

### Описание

Быстрое добавление комментария доступно в онлайн и офлайн-режиме.

Возможность добавления комментариев зависит от прав доступа текущего пользователя.

### Место в интерфейсе

Экран "Комментарии ()".

### Выполнение действия

1. Откройте экран "Комментарии ()".
2. Нажмите на поле ввода комментария на нижней панели экрана и введите текст комментария с помощью стандартных виджетов ввода текста Android.

    ![Экран "Комментарии ()"](./comm_A_6_15.png)
3. Дополнительные возможности:
    - Отметить как приватный — чтобы отметить комментарий как приватный, включите переключатель "Приватный".
    - Добавить упоминание — нажмите иконку ![](../actions-2/mail.png) и на отдельном экране выберите объекты для упоминания.

        Для выбора доступны объекты только того класса, для которого настроено правило упоминаний с префиксом @.

        ![Экран со списком выбора объектов упоминания](./obj_ref_list_A.PNG)

        Выбранное упоминание отобразится в тексте комментария в виде ссылки, выделенной синим цветом. Если упоминаний несколько, то они перечисляются через запятую.

        ![Добавление упоминания в комментарии](./comm_A_2_15.png)
    - Прикрепить файл из библиотеки или фото — нажмите иконку ![](./i_file.png){height=12} и выберите соответствующий инструмент мобильного устройства.

        Добавленный файл отображается над полем ввода комментария. Рядом с иконкой ![](./i_file.png){height=12} отображается количество прикрепленных файлов.

        Иконки в нижней панели экрана недоступны для нажатия до полной загрузки всех прикрепленных файлов.
    - Добавить форматирование и/или заполнить дополнительные атрибуты — нажмите иконку ![](./01_1.png) для перехода на отдельный экран, см. [Расширенное добавление комментария. Android](./comment-add-ext-2).
4. Нажмите иконку "Отправить комментарий".

### Результат действия

Новый комментарий отобразится на экране "Комментарии ()". Приватные комментарии отмечены надписью "Приватный".

Особенности офлайн-режима:

- Для добавления комментария в офлайн-режиме экран карточки объекта должен быть сохранен в кеше приложения.
- После добавления комментарий помещается в очередь синхронизации. На экране отображается сообщение: "Комментарий добавлен в очередь синхронизации и будет отправлен при появлении доступа к серверу".
- Время добавления комментария будет соответствовать дате и времени синхронизации с сервером.

Подробное описание офлайн-режима приведено в разделе [Офлайн-режим. Android](../offline-2).
